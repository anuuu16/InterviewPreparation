## Basic

### 1. What is a variable, and what is a data type?

**Short answer:** A variable is a named box in memory that holds a value. A data type says what kind of value it is (number, text, true/false, list) and what you can do with it.

**What a good answer has:** an example such as `age = 21` and `name = "Asha"`, and the idea that `"5" + 1` is not the same as `5 + 1` because the types differ.

**Follow-up:** What happens if you add a number and a text? (Depends on the language: an error in Python, a joined text in JavaScript.)

**Red flag:** cannot name three types. Memorised a definition but cannot give an example.

**Interview tip:** Start with this one to relax the candidate. Anyone with a college programming course should get it.

_Module: Programming Basics · Tags: basics, variables_

### 2. What is the difference between a `for` loop and a `while` loop?

**Short answer:** A `for` loop is used when you know how many times to repeat, for example once per item in a list. A `while` loop repeats as long as a condition is true, so it fits when you do not know the count in advance, for example "read until the user types quit".

**What a good answer has:** the three parts of a loop (start, condition, update) and what an infinite loop is: the condition never becomes false because the update is missing.

**Follow-up:** How do you stop a loop early? (`break`.) How do you skip one round? (`continue`.)

**Red flag:** says "there is no difference" without explaining when to choose each.

_Module: Programming Basics · Tags: basics, loops_

### 3. What is a function and why do we use functions?

**Short answer:** A function is a named block of code that takes input (parameters), does one job and can return a result. We use it to avoid repeating code, to test small pieces, and to make a program easier to read.

**What a good answer has:** a small example, like `isEven(n)`, and the words "reuse" and "readability".

**Follow-up:** What is the difference between a parameter and an argument? (Parameter is the name in the definition, argument is the actual value you pass.)

**Red flag:** writes one huge function for everything in their projects.

_Module: Programming Basics · Tags: basics, functions_

### 4. Explain Object-Oriented Programming in simple words.

**Short answer:** OOP organises code around objects, which bundle data and the actions on that data. The four ideas are encapsulation (hide the details, expose a few methods), abstraction (show only what matters), inheritance (a child class reuses a parent class) and polymorphism (the same method call behaves differently for different objects).

**What a good answer has:** a real-life example, such as `Car` with `start()`, and `ElectricCar` that inherits from `Car` and starts differently.

**Follow-up:** What is the difference between a class and an object? (Class is the blueprint, object is one thing built from it.) When would you use composition instead of inheritance?

**Red flag:** can recite the four words but cannot give a single example.

_Module: Programming Basics · Tags: oop, basics_

### 5. What is the difference between a class and an object?

**Short answer:** A class is a blueprint that describes the data and behaviour. An object is one real instance made from that blueprint, with its own values.

**What a good answer has:** "House plan versus the actual houses". Two objects of the same class can hold different values.

**Follow-up:** What is a constructor? (Special method that runs when the object is created and sets it up.)

_Module: Programming Basics · Tags: oop_

### 6. What is the difference between a compiled and an interpreted language?

**Short answer:** A compiled language (C, C++, Go) is translated to machine code before it runs, so it usually starts and runs faster. An interpreted language (Python, JavaScript) is read and run line by line by another program. Many languages are in between: Java compiles to bytecode that a virtual machine runs.

**Follow-up:** Which category is Java? Which is TypeScript? (TypeScript compiles to JavaScript.)

**Interview tip:** Do not push on exact details. A fresher who knows "compile first, or run directly" is fine.

_Module: Programming Basics · Tags: basics, languages_

### 7. What is variable scope?

**Short answer:** Scope is the part of the program where a variable can be used. A variable declared inside a function is local and not visible outside. A global variable is visible everywhere, which is why it is risky: any code can change it.

**Follow-up:** What happens if a local and a global variable have the same name? (The local one hides the global one inside the function.)

_Module: Programming Basics · Tags: basics, scope_

### 8. What is the difference between an error and an exception? How do you handle exceptions?

**Short answer:** An exception is a problem that happens while the program runs, such as dividing by zero or opening a file that does not exist. You handle it with `try` and `catch` (or `try` and `except`), so the program can show a message or recover instead of crashing.

**What a good answer has:** `finally` for cleanup, and not swallowing errors silently with an empty catch.

**Follow-up:** Name three kinds of mistakes: syntax errors (code does not parse), runtime errors (crash while running), logic errors (runs but gives wrong result). Which is hardest to find? (Logic errors, because nothing complains.)

_Module: Programming Basics · Tags: errors_

### 9. Swap two variables without using a third one.

**Short answer:** In Python and JavaScript, use tuple or destructuring swap: `a, b = b, a` or `[a, b] = [b, a]`. The classic trick works with numbers: `a = a + b; b = a - b; a = a - b`. XOR also works: `a ^= b; b ^= a; a ^= b`.

**What a good answer has:** knows at least one method. The best candidates also say that in real code you just use a temp variable or destructuring, because clever tricks hurt readability and the arithmetic trick can overflow in languages with fixed-size integers.

**Follow-up:** Trace it with a = 5, b = 3: a becomes 8, b becomes 5, a becomes 3.

_Module: Logic & Puzzles · Tags: logic, coding_

### 10. How do you check whether a string is a palindrome?

**Short answer:** Compare the string with its reverse, or use two pointers: one at the start and one at the end, move inwards and stop at the first mismatch. Two pointers needs no extra memory.

**What a good answer has:** thinks about edge cases: empty string, single character, upper and lower case, spaces and punctuation ("A man, a plan, a canal: Panama").

**Follow-up:** What is the time complexity? (O(n) time, O(1) space for two pointers.)

_Module: Logic & Puzzles · Tags: logic, strings, coding_

### 11. Reverse a string without using the built-in reverse function.

**Short answer:** Loop from the last character to the first and build a new string, or convert to a list and swap the first and last, second and second last, and so on until you meet in the middle.

**Follow-up:** Why is repeated string concatenation in a loop slow in some languages? (Strings are immutable, so each step may copy the whole string.) How would you reverse the words of a sentence instead of letters?

_Module: Logic & Puzzles · Tags: logic, strings, coding_

### 12. How do you check whether a number is prime?

**Short answer:** A prime is greater than 1 and divisible only by 1 and itself. Try dividing by every number from 2 up to the square root of n. If any divides evenly, it is not prime. You can stop at the square root because factors come in pairs, and one of each pair is at most the square root.

**What a good answer has:** handles 0, 1 and 2 correctly. A brute force loop up to n is acceptable at first; the square-root improvement is the stronger answer.

**Follow-up:** How would you list all primes up to a million? (Sieve of Eratosthenes.)

_Module: Logic & Puzzles · Tags: logic, math, coding_

### 13. Count how often each character appears in a string.

**Short answer:** Use a hash map (dictionary) from character to count. Loop over the string and add one to the count for each character. One pass, O(n) time.

```python
text = "banana"
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)   # prints: {'b': 1, 'a': 3, 'n': 2}
```

**Follow-up:** How would you find the first character that appears only once? (Second pass over the string, checking the count.) How would you check whether two words are anagrams? (Compare their counts.)

_Module: Logic & Puzzles · Tags: logic, hashing, coding_

### 14. A farmer has a wolf, a goat and a cabbage and must cross a river in a boat that carries only the farmer and one item. How?

**Short answer:** Take the goat across. Go back alone. Take the wolf across, and bring the goat back. Take the cabbage across, go back alone, and take the goat across again. The wolf and the goat are never left together, and the goat and the cabbage are never left together.

**What a good answer has:** the key step of bringing the goat back. Candidates who see that moving something backwards can help are thinking well.

_Module: Logic & Puzzles · Tags: puzzle, classic_

### 15. At a party of 10 people everyone shakes hands with everyone else once. How many handshakes?

**Short answer:** 45. Each of the 10 people shakes hands with 9 others, which counts every handshake twice, so 10 x 9 / 2 = 45. The general formula is n x (n - 1) / 2.

**Follow-up:** Where does this show up in software? (The number of connections in a fully connected network, or the number of pairs you compare in a brute force search.)

_Module: Logic & Puzzles · Tags: puzzle, math_

### 16. Convert the decimal number 13 to binary. Why do computers use binary?

**Short answer:** 13 is 1101 in binary: 8 + 4 + 0 + 1. Computers use binary because electronic circuits have two reliable states, on and off, and it is simple and cheap to build hardware that tells them apart.

**Follow-up:** How many different values can 8 bits hold? (256.) What is 2 to the power of 10? (1024.)

_Module: Logic & Puzzles · Tags: binary, basics_

### 17. What is the difference between an array and a linked list?

**Short answer:** An array stores items next to each other in memory, so you can jump to any index in constant time, but inserting in the middle means shifting items. A linked list stores each item with a pointer to the next one, so inserting is cheap once you are at the spot, but finding the 50th item means walking through 50 nodes.

**What a good answer has:** a comparison table in words: access by index, insert at the start, insert in the middle, memory use.

**Follow-up:** Which one would you use for a playlist where users reorder songs a lot? What is a doubly linked list?

_Module: Data Structures & Algorithms · Tags: data-structures_

### 18. What is the difference between a stack and a queue? Give a real-life example of each.

**Short answer:** A stack is last in, first out: the last item added is the first removed, like a pile of plates, or the undo button. A queue is first in, first out, like people waiting in line, or print jobs.

**Follow-up:** Which one does the function call mechanism use? (The call stack.) Which one would you use to process tasks in order? (A queue.)

_Module: Data Structures & Algorithms · Tags: data-structures_

### 19. When can you use binary search, and what is its time complexity?

**Short answer:** Binary search works on sorted data. It compares the target with the middle item and throws away half of the items each step, so it takes O(log n) time. One million items need about 20 steps.

**What a good answer has:** says "sorted" without being prompted. A good candidate also writes the middle as `low + (high - low) / 2` and loops `while low <= high`.

**Follow-up:** What happens if the array is not sorted? How would you find the first occurrence of a duplicate value?

_Module: Data Structures & Algorithms · Tags: algorithms, searching_

### 20. Explain how bubble sort works, and name a faster sorting algorithm.

**Short answer:** Bubble sort walks through the list, compares neighbours and swaps them if they are in the wrong order. After each pass the largest item has bubbled to the end. It repeats until no swaps happen. It takes O(n squared) time, which is slow for big inputs. Merge sort and quick sort take O(n log n) on average.

**Follow-up:** What does stable sorting mean? (Equal items keep their original order.) What sort does your language use internally? (Python and Java use Timsort for objects.)

_Module: Data Structures & Algorithms · Tags: algorithms, sorting_

### 21. How would you find duplicates in an array?

**Short answer:** Loop through and keep a set of values already seen. If the value is already in the set it is a duplicate. This is O(n) time and O(n) space. Brute force with two loops uses no extra memory but takes O(n squared). Sorting first and comparing neighbours is O(n log n) with little extra memory.

**What a good answer has:** names the trade-off between time and memory, not only one solution.

_Module: Data Structures & Algorithms · Tags: algorithms, hashing, arrays_

### 22. What is the difference between GET and POST? Name some HTTP status codes.

**Short answer:** GET asks the server for data and should not change anything. POST sends data to the server to create or change something, and the data goes in the request body. Common status codes: 200 OK, 201 Created, 301 redirect, 400 bad request, 401 not logged in, 403 not allowed, 404 not found, 500 server error.

**Follow-up:** Why should you not send a password with GET? (It ends up in the URL, browser history and logs.)

### 23. What is an API? What does REST mean?

**Short answer:** An API is a way for one program to talk to another with agreed rules. A REST API uses plain HTTP: URLs name things (`/users/5`), and methods say what to do with them (GET to read, POST to create, PUT or PATCH to update, DELETE to remove). Data usually travels as JSON.

**Follow-up:** What is JSON? (A text format for data, with objects and arrays, easy for people and programs to read.)

_Module: Web, Databases & Git · Tags: web, api_

### 24. What do HTML, CSS and JavaScript each do in a web page?

**Short answer:** HTML is the structure and content: headings, paragraphs, buttons. CSS is the look: colours, layout and spacing. JavaScript is the behaviour: it reacts to clicks, changes the page and talks to servers.

**Red flag:** for a candidate who says they know web development, cannot tell them apart.

### 25. What is the difference between authentication and authorization?

**Short answer:** Authentication checks who you are, for example with a password. Authorization checks what you are allowed to do, for example an admin can delete users and a normal user cannot.

**Follow-up:** Why should you never store passwords as plain text? (A leak exposes everyone. Store a salted hash.)

_Module: Web, Databases & Git · Tags: web, security_

### 26. What is the difference between SQL and NoSQL databases? What is a primary key?

**Short answer:** SQL databases store data in tables with fixed columns and relate tables with keys and joins (PostgreSQL, MySQL). NoSQL databases store data in other shapes, such as documents or key-value pairs, and are often more flexible about structure (MongoDB, Redis). A primary key is a column whose value uniquely identifies each row.

**Follow-up:** What is a foreign key? (A column that points to the primary key of another table.)

_Module: Web, Databases & Git · Tags: databases_

### 27. What is Git and what is the difference between commit, push and pull?

**Short answer:** Git is a version control system that records the history of your code. A commit saves a snapshot on your computer. Push sends your commits to the remote repository, such as GitHub. Pull fetches new commits from the remote and merges them into your branch.

**Follow-up:** What is a branch and why use one? What is a merge conflict and how do you fix it? (Two people changed the same lines. Open the file, choose the right content, remove the markers, commit.)

**Red flag:** has never used Git at all. That is a gap to note for any internship that involves a team.

_Module: Web, Databases & Git · Tags: git_

### 28. Your program runs but prints the wrong output. How do you find the problem?

**Short answer:** Reproduce it with the smallest input. Read the code and work out what each step should do. Print values at key steps (or use a debugger with breakpoints) to find the first place where reality differs from what you expected. Fix the cause, then run the test again and check nearby cases.

**What a good answer has:** a process, not "I stare at it" or "I ask someone". Mentions a debugger, print statements, small inputs and checking assumptions.

**Interview tip:** Ask for a real bug they fixed and what finally showed the problem.

_Module: Debugging & Problem Solving · Tags: debugging_

### 29. What is wrong with this loop? `for (i = 0; i <= arr.length; i++) { sum += arr[i]; }`

**Short answer:** It is an off-by-one error. Indexes run from 0 to length minus 1, so `<=` goes one step too far and reads past the end. In JavaScript it adds `undefined` and gives `NaN`, in Java it throws an exception. Use `i < arr.length`.

**What a good answer has:** finds it in a few seconds and names the cause.

**Follow-up:** Where else do off-by-one errors show up? (Binary search bounds, substring ranges, pagination.)

_Module: Debugging & Problem Solving · Tags: debugging, coding_

### 30. What is a unit test and why write one?

**Short answer:** A unit test is a small automated check for one piece of code, such as a function. You write what input you give and what you expect back. Tests catch bugs early, show that old behaviour still works after a change, and act as living examples of how the code should be used.

**Follow-up:** What cases would you test for a function that finds the maximum of a list? (Normal, one item, negatives, duplicates, empty list.)

_Module: Debugging & Problem Solving · Tags: testing_

### 31. You are stuck on a problem for two hours. What do you do?

**Short answer:** First, break the problem down and check basic assumptions. Try a smaller version, search the documentation, and explain it aloud to someone or to a rubber duck. If still stuck after a set time, ask a teammate or mentor, showing what I tried so they do not start from zero.

**What a good answer has:** a balance between trying alone and asking for help. Both extremes are problems: never asking wastes days, asking at once without trying shows no effort.

### 36. What is the difference between `=` and `==`?

**Short answer:** A single `=` assigns a value: `x = 5` puts 5 in `x`. A double `==` compares two values and gives true or false: `x == 5` asks whether `x` is 5. Mixing them up is a classic beginner bug, for example writing `if (x = 5)`, which assigns instead of comparing.

**Follow-up:** In JavaScript, what is the difference between `==` and `===`? (`===` also compares the type, so `"5" === 5` is false.)

**Red flag:** cannot explain it after a college programming course.

_Module: Programming Basics · Tags: basics, operators_

### 37. Why do array indexes usually start at 0?

**Short answer:** The index is the distance from the start of the array. The first item is zero steps from the start, so it has index 0. The last item of an array with 5 items has index 4.

**What a good answer has:** knows the last index is length minus one, and can say what happens when you use index 5 on 5 items (error or undefined).

**Follow-up:** How do you get the last item of an array in your language?

_Module: Programming Basics · Tags: basics, arrays_

### 38. How do an `if-else` and a `switch` differ? When do you use each?

**Short answer:** `if-else` checks any conditions, such as ranges or combinations (`age > 18 and hasId`). `switch` compares one value against a list of fixed choices, such as the day of the week or a menu option. Use `switch` when there are many exact matches, otherwise `if-else`.

**Follow-up:** What happens if you forget `break` in a `switch` in C, Java or JavaScript? (Execution continues into the next case.)

_Module: Programming Basics · Tags: basics, conditions_

### 39. What is the difference between frontend and backend?

**Short answer:** The frontend is what the user sees and touches in the browser or app: pages, buttons, forms. The backend runs on a server, holds the business rules, talks to the database and sends data to the frontend. When you log in, the frontend collects your password and the backend decides whether it is correct.

**Follow-up:** Which side would you pick to work on and why? Where should input validation happen? (On both: frontend for friendly messages, backend for safety.)

### 40. Why does an application need a database? Why not just a file?

**Short answer:** A database stores data safely and lets many users read and change it at the same time, with fast searching, rules about the data and recovery after a crash. A plain file is fine for small, single-user data, but it gets slow, is easy to corrupt and cannot handle two people writing at once.

**Follow-up:** Give an example of data you would put in a database in a shopping app. (Users, products, orders.)

### 41. What does this print? `total = 0` then `for i in 1, 2, 3: total += i * i` then `print(total)`

### 42. What is an algorithm? Write the steps to make a cup of tea.

**Short answer:** An algorithm is a clear list of steps that solves a problem and always ends. For tea: boil water, put a tea bag in the cup, pour water, wait three minutes, remove the bag, add milk and sugar if wanted.

**What a good answer has:** steps in the right order, no missing step, and then a decision in it: "if the water is not hot yet, wait". Strong candidates add conditions and repetition, which are the same as `if` and loops in code.

### 43. Print a triangle of stars with 4 rows using loops. The first row has 1 star and the last has 4.

**Short answer:** Use an outer loop for the rows and an inner loop that prints as many stars as the current row number, then moves to a new line.

```python
for row in range(1, 5):
    for _ in range(row):
        print("*", end="")
    print()      # new line after each row
```

**What a good answer has:** can explain what the outer and inner loop each do. Pattern questions show whether the candidate understands nested loops.

**Follow-up:** How would you print the triangle upside down? How would you print a pyramid with spaces on the left?

### 44. Count the vowels in a sentence. What cases do you need to think about?

**Short answer:** Go through each character and add one if it is one of a, e, i, o, u. To handle upper case letters, convert the character to lower case first. Other characters such as spaces, digits and punctuation are skipped.

**What a good answer has:** handles upper and lower case, an empty string, and says whether "y" counts (it normally does not here).

### 45. Which is heavier: a kilo of cotton or a kilo of iron?

### 55. What does the JavaScript expression `'5' + 3` give? What about `'5' - 3`?

### 56. What is the difference between `let`, `const` and `var` in JavaScript?

**Short answer:** `let` and `const` are block scoped and `var` is function scoped, so `var` can leak out of a block like an `if` or a loop. `let` can be reassigned. `const` cannot be reassigned, but if it holds an object or array, the contents can still change. Modern code uses `const` by default and `let` when the value must change.

### 64. What is recursion? What can go wrong with it?

**Short answer:** Recursion is a function that calls itself on a smaller version of the problem until it reaches a simple case that it can answer directly. That simple case is the base case. Without it the calls never stop and the program crashes with a stack overflow.

**What a good answer has:** factorial or Fibonacci as the example, and the base case named clearly.

```python
def factorial(n):
    if n <= 1:          # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))     # prints: 120
```

**Follow-up:** Why can plain recursive Fibonacci be very slow? (It repeats the same work. Fix with memoisation or a loop.)

**Red flag:** no base case in their example.

_Module: Programming Basics · Tags: recursion_

### 65. What is the difference between pass by value and pass by reference?

**Short answer:** Pass by value gives the function a copy, so changing it does not affect the caller. Pass by reference gives the function access to the original, so changes are visible outside. In Python and JavaScript, numbers and strings behave like a copy, while lists and objects can be changed from inside a function because the function receives a reference to them.

**Follow-up:** What does this print? `def add(xs): xs.append(1)` then `a = []; add(a); print(a)` (prints `[1]`.)

**Red flag:** says "everything is pass by value" or "everything is pass by reference" with total confidence and no nuance.

_Module: Programming Basics · Tags: basics, memory_

### 66. Find the largest and the second largest number in an array in one pass.

**Short answer:** Keep two variables, `largest` and `second`. For each number: if it is bigger than `largest`, then `second` takes the old `largest` and `largest` takes the new number. Otherwise, if it is bigger than `second` and not equal to `largest`, update `second`. One pass, O(n) time, O(1) space.

**What a good answer has:** handles duplicates (`[5, 5, 3]` has second largest 3), an array with fewer than two distinct values, and negative numbers (do not start with 0).

**Red flag:** sorts the array without being asked about cost, and cannot say what it costs. Sorting is acceptable if they say it is O(n log n) and that one pass is better.

### 67. An array has the numbers 1 to n, with one number missing. Find it.

**Short answer:** The sum of 1 to n is `n * (n + 1) / 2`. Subtract the sum of the array from it and the difference is the missing number. It takes one pass and no extra memory. Alternatives: a set lookup (extra memory) or XOR of all numbers.

**What a good answer has:** a first idea that works (sorting or a set) and, with a hint, the sum formula.

**Follow-up:** What if two numbers are missing? (Use the sum and the sum of squares, or a boolean array.) What if the sum overflows? (Use a wider type or XOR.)

### 68. ⭐ Given an array and a target, find two numbers that add up to the target.

**Short answer:** Brute force checks every pair, which is O(n squared). Better: walk through the array once, and for each number look up `target - number` in a hash map of numbers seen so far. If found, you have the pair. O(n) time and O(n) space.

**What a good answer has:** starts with brute force, then improves. Mentions that using the same element twice is not allowed, and asks whether the input is sorted (if so, two pointers need no extra memory).

**Interview tip:** This is the best single question to separate people who can improve a solution from people who only know one. Give credit for the process, not only the final code.

### 69. You have a 3-litre jug and a 5-litre jug and no markings. How do you measure exactly 4 litres?

**Short answer:** Fill the 5-litre jug. Pour into the 3-litre jug until it is full, leaving 2 litres in the 5. Empty the 3-litre jug. Pour the 2 litres into it. Fill the 5-litre jug again. Pour from it into the 3-litre jug, which only needs 1 more litre, so 4 litres remain in the 5-litre jug.

### 70. You have 8 balls that look the same. One is heavier. Using a balance scale, what is the minimum number of weighings to find it?

**Short answer:** Two weighings. Weigh 3 balls against 3 balls. If they balance, the heavy ball is one of the remaining 2, so weigh those two against each other. If one side is heavier, take those 3 balls, weigh any 2 against each other: if one is heavier it is the answer, if they balance the third one is.

### 73. What is the angle between the hour and minute hands at 3:15?

### 78. Why does 0.1 + 0.2 not equal 0.3 in most programming languages?

**Short answer:** Computers store decimals in binary, and some decimal fractions such as 0.1 cannot be stored exactly in binary, just like one third cannot be written exactly in decimal. So the result is 0.30000000000000004 and the comparison with 0.3 is false.

**What a good answer has:** the practical fix: compare with a small tolerance, or store money as whole cents (integers) or use a decimal type.

**Red flag:** says "it is a bug in the language".

**What a good answer has:** knows that `and` needs both sides true and `or` needs only one, and that brackets make it clear.

### 80. Find the sum of the digits of a number, and reverse the number, without converting it to a string.

**Short answer:** Repeat while the number is greater than 0: the last digit is `n % 10`, add it to the sum, and then remove it with integer division `n // 10`. To reverse, build the new number with `reversed = reversed * 10 + digit`. For 1234 the digit sum is 10 and the reversed number is 4321.

**What a good answer has:** understands that `% 10` gives the last digit and dividing by 10 drops it. Works through the example on paper.

### 81. A snail is at the bottom of a 10-metre well. Each day it climbs 3 metres, and each night it slips back 2 metres. How many days to get out?

### 82. A father is three times as old as his son. After 12 years he will be twice as old as his son. How old are they now?

### 90. Explain an INNER JOIN with an example.

**Short answer:** A join combines rows from two tables using a matching column. An INNER JOIN returns only the rows that have a match in both tables. For example, orders and customers joined on `customer_id` gives each order with the name of the customer who made it. Orders without a matching customer do not appear.

```sql
SELECT c.name, o.total
FROM orders o
INNER JOIN customers c ON c.id = o.customer_id;
```

**Follow-up:** How is a LEFT JOIN different? (It also keeps the rows from the left table that have no match, filling the other side with NULL.)
