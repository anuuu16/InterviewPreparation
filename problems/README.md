# Problems

[← Back to the main index](../README.md)

Popular interview problems with a written guide and tested code in several languages. Each problem explains the idea, how interviewers ask it, real-life uses, and every common approach from simple to optimal.

| Problem | Level | Approaches | Languages | Summary |
| --- | --- | --- | --- | --- |
| [Sorting](sorting/README.md) | basic | 7 | 7 | Put items in order: the building block behind search, ranking, deduplication and merging. |
| [Binary search](binary-search/README.md) | basic | 5 | 7 | Find an item in sorted data by halving the search window: the idea behind index lookups, git bisect and many 'search on the answer' problems. |
| [Two sum](two-sum/README.md) | basic | 3 | 7 | Find two numbers that add up to a target: the classic way to learn why a hash map turns a slow search into a fast lookup. |
| [Valid parentheses](valid-parentheses/README.md) | basic | 3 | 7 | Check that every bracket is closed in the right order: the classic way to learn why a stack fits "last opened, first closed". |
| [Linked list](linked-list/README.md) | basic | 5 | 7 | Reverse a list, find a cycle and merge two sorted lists: the classic pointer problems that teach you to rewire nodes without losing the rest of the list. |
| [Tree traversals](tree-traversals/README.md) | basic | 3 | 7 | Visit every node of a binary tree in pre-order, in-order, post-order or level order: the base for searching, copying, printing and validating trees. |
| [Fibonacci and dynamic programming](fibonacci-dynamic-programming/README.md) | basic | 5 | 7 | Use Fibonacci to learn dynamic programming: why naive recursion repeats work, and how memoisation, tabulation and a rolling window fix it. Includes climbing stairs. |
| [LRU cache](lru-cache/README.md) | intermediate | 2 | 7 | Design a cache that evicts the least recently used item, with constant-time get and put: the classic design problem that combines a hash map and a linked list. |
| [Anagrams](anagrams/README.md) | basic | 4 | 7 | Decide whether two words use the same letters, and group a list of words into anagram families: a classic lesson in choosing a good hash key. |
| [Number of islands](number-of-islands/README.md) | intermediate | 4 | 7 | Count the connected groups of land in a grid: the classic way to learn flood fill with depth-first search, breadth-first search and union-find. |
